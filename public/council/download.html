    Building it yourself

    Council is a Flutter app and the source is public. If you would rather build it than wait for a release: 

    git clone https://github.com/SpencerSmithSite/council.git
cd council
flutter pub get

# Pick your platform
flutter run -d macos
flutter run -d windows
flutter run -d linux
flutter run            # a connected phone or emulator

    You will need Flutter 3.x and the toolchain for whichever platform you are targeting. No API keys or accounts are needed to build or run it.
